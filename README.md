# VinTheKid Website

A responsive creator website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `VinTheKidSite`.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js` and `assets` folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The address will look like:
   `https://YOUR-USERNAME.github.io/VinTheKidSite/`

## Notes
- The contact form uses `mailto:`. It opens the visitor's email application with the message filled in; it does not send email silently from the website. A true in-page email sender needs a trusted form service or a server-side function.
- The YouTube Live button opens the channel's `/live` page. This static site does not verify live status automatically.
- The intro uses a photorealistic Ferrari-themed creator artwork with a cinematic zoom, perspective, glow and scan animation; it runs for about 4.3 seconds and includes a Skip Intro button. The car artwork is a rendered image with motion effects, not a live interactive 3D model.
- Update the links or email in `index.html` if they change.
